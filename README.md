# ChurnIQ — E-Commerce Customer Churn Prediction
A full-stack ML web application built with Python, Scikit-learn, and Flask.

---

## 🚀 Quick Start

### Step 1: Install dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Generate dataset + train model
```bash
python generate_data_and_model.py
```
This will:
- Create `data/ecommerce_churn.csv` (50,000 rows)
- Train Logistic Regression + Random Forest
- Save `model/churn_model.pkl`, `model/scaler.pkl`, `model/encoders.pkl`
- Save `model/stats.json` for the dashboard

### Step 3: Run the Flask app
```bash
python app.py
```

Open your browser at: **http://localhost:5000**

## 🤖 Model Details
- **Algorithm**: Random Forest (100 estimators) + Logistic Regression
- **Features**: 17 (14 raw + 3 derived)
- **Target**: Binary churn (Yes/No)
- **Evaluation**: Accuracy, AUC-ROC, Confusion Matrix, Classification Report
